🥐 Marzipan Bakery - Digital Experience
פלטפורמת e-commerce מודרנית למאפיית "מרציפן" המפורסמת בירושלים. הפרויקט נבנה כיישום React מלא (SPA) השם דגש על חווית משתמש (UX) חלקה, ביצועים גבוהים וממשק הזמנות אינטואיטיבי.

📌 סקירת הפרויקט
האתר מנגיש את הקטלוג העשיר של המאפייה ומאפשר למשתמשים לבצע הזמנות מותאמות אישית בצורה מהירה. האתגר המרכזי היה ניהול מצב (State Management) מורכב של עגלת קניות וסינון מוצרים דינמי, כל זאת תוך שמירה על רספונסיביות מלאה.

🛠️ ארכיטקטורה וטכנולוגיות
Frontend: React.js עם שימוש נרחב ב-Hooks (useState, useEffect, useMemo).

State Management: שימוש ב-Context API לניהול גלובלי של עגלת הקניות, המאפשר סנכרון נתונים בין דפים שונים ללא "Prop Drilling".

Routing: React Router 6 לניהול ניווט דינמי ושימוש ב-Query Parameters לסינון קטגוריות.

Styling: Tailwind CSS לעיצוב מודרני, מהיר ורספונסיבי (Mobile-First approach).

Integration: הטמעת ממשק שליחה ל-WhatsApp להשלמת תהליך הרכישה ללא צורך ב-Backend מורכב.

✨ פיצ'רים מרכזיים ומורכבות טכנית
🛒 מערכת עגלת קניות חכמה
ניהול כמויות בזמן אמת וחישוב סכומים אגרגטיבי.

שימוש ב-Persistence (אופציונלי להוסיף: LocalStorage) לשמירת העגלה גם לאחר ריענון הדף.

🔍 קטלוג מוצרים וסינון מתקדם
מנגנון חיפוש וסינון קטגוריות המבוסס על ניתוב (URL parameters), המאפשר למשתמשים לשתף לינקים לסינונים ספציפיים.

📬 Checkout & Validation
טופס הזמנה הכולל ולידציית קלט (Client-side validation) למניעת שגיאות לפני שליחת ההזמנה.

יצירת הודעת WhatsApp מובנית הכוללת את פירוט הפריטים, כמויות וסיכום סופי בצורה אסתטית.

📂 מבנה תיקיות (Clean Code)
הפרויקט בנוי בצורה מודולרית המפרידה בין לוגיקה לתצוגה:

components/ - קומפוננטות UI ברות שימוש חוזר (Reusable Components).

context/ - ניהול המצב הגלובלי של האפליקציה.

pages/ - דפי האפליקציה המרכזיים.

data/ - "Single source of truth" למידע על המוצרים.

👨‍💻 תובנות מהפיתוח
במהלך הפרויקט העמקתי בפתרון בעיות הקשורות ל-Performance ב-React, עבודה עם מערכי נתונים גדולים בקטלוג, ויצירת ממשק משתמש נגיש ונוח.
